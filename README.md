🏅 Olympic Medalists Through the Years
What 120 years of Olympic data says about who wins, where they're from, and how that has changed

The Olympics have been held for more than a century. Who has done the winning in that time? This project uses Python to analyze Olympic medalist records from 1896 to 2016 and answers three questions:

Which countries have won the most Olympic medals overall?
Has the typical age of an Olympic medalist changed over time?
How has the share of medals won by women grown since the early Games?

📊 About the Data

The dataset covers Olympic medalists from 1896 through 2016. Each row is one athlete's result in one event, so team events count each team member separately. Because of that, the totals here can be higher than official national medal counts.
